# Dr. Seph's Courses

My collection of courses including the raw Python code using the Manim library, Jupyter Notebook files, and individual lecture video files before editing and adding my voiceover narration. Open the .md files to display the code and in-line output videos that demonstrate my creative process.

Here is a **tentative release schedule for the completed courses** that will be available for purchase:

Apr. 2027: Pre-Algebra, Algebra \
Jun. 2027: Pre-Calculus, Statistics \
Aug. 2027: Calculus 1, Calculus 2 \
Oct. 2027: Calculus 3 \
Dec. 2027: Discrete Mathematics \
Feb. 2028: Differential Equations, Linear Algebra

Throughout the process I will be posting completed lecture videos on YouTube (possibly trimmed down from the full, purchasable length).

The courses themselves will be comprised of the full-length lecture videos, practice problems, and potentially other features such as practice tests and additional assistance from me. Perhaps an exclusive community feature where you can seek help from other students and I.

This business is how I intend to make a living after resigning from my full professorship in Dec. 2026, so any and all help is greatly appreciated (whether monetary or otherwise)

All published lectures will be edited and narrated by me

No AI will be used in the production process (no AI voiceovers, AI coding, AI-generated assets, etc.) \
This project is intended to be a human-first endeavor
